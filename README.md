# 07-revflow（冲流台）

冲流台 — 正向与冲正流水净额归并：正向装载 → 冲正关联入账 → 净额归并落余额 → 未平/超额隔离 → 流水净额与余额互证。

**不是** 多源 Feed 归并，**不是** 作业依赖编排，**不是** CDC 变更流，**不是** 质检签发，**不是** 数仓分层建设，**不是** 交班过户。  
**也不是** 收银/退款 CRUD 后台、电商订单、报表 CSV 看板——主链是**流水管道与净额状态**，不是业务单据编辑台。

## 主链

账户登记 → 装载正向流水 → 装载冲正并关联原单 → 跑净额归并（已配平落余额，未平/超额进隔离）→ 互证报告核对「流水净额 vs 账户余额」

## 多币种折算与冻结汇率（fx_settle）

归并采用「开跑冻结、趟内只读」的汇率策略，杜绝按行实时取价导致同批重跑净额漂移：

1. **开跑冻结**：归并开始先把本趟涉及的「币种 → 记账币(CNY)」汇率一次性从牌价表 `fx_rates` 读出，写入独立快照表 `fx_rate_snapshots`（挂 `settle_run_id`）。快照表有 UPDATE/DELETE 触发器，落库即不可变，可随时回看。
2. **趟内只读快照**：本趟所有正向/冲正的折算只查冻结集；每条流水落 `fx_rate_snapshot_id` + `converted_cents` 作为汇率证据，纯函数折算（ROUND_HALF_UP），同一流水键同趟结果稳定。
3. **失败闭原子切换**：整趟在单个事务内提交；缺牌价或中途异常整单回滚，不残留进行中运行或半折算账户。
4. **互证同源**：互证报告展示的冻结汇率直接读落库快照，并按快照逐条复算折算、校验快照归属与跨趟余额守恒，禁止内存汇率表冒充证据。
5. **可查看**：账户页与归并台均可展开某趟的汇率快照与每账户原币/折算净额。

牌价为 as-of 取值（`effective_at <= 冻结时刻` 的最新一条）；新一趟只冻结新快照，历史趟的快照与折算结果不受后续汇率变动影响。

## 界面约定

页面文案全部中文；入口：总览 / 账户 / 正向流水 / 冲正流水 / 归并台 / 未平隔离 / 净额互证。  
视觉：**左轨编号导航 + 右侧账册横线工作面**（Literata / JetBrains Mono，靛蓝强调）；**不是**交班台那种顶栏品牌+横向流程条。
